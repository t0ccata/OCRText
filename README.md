Android OCR Text Recognition App 📱🔍

A lightweight and fast Android application built with Google ML Kit and Kotlin that allows users to open the app, capture an image directly using the camera, and instantly extract text from it.

✨ Features

Camera-Driven OCR: Open the app and take a photo to detect and extract text immediately.

Instant Text Detection: Powered by Google's on-device ML Kit Text Recognition API for fast and accurate text extraction.

On-Device Processing: Works completely offline without requiring an internet connection or external server requests, ensuring user privacy and low latency.

Minimalist UI: Simple and clean interface designed for quick scanning and text copying.

🛠️ Tech Stack & Libraries

Language: Kotlin

Core OCR Engine: Google ML Kit (Text Recognition)

Camera API: CameraX

Minimum SDK: API 24 (Android 7.0) or higher

🚀 How It Works

Open App: Launch the application on your Android device.

Grant Camera Permission: Allow camera access when prompted (first-time setup).

Capture & Detect: Point the camera at any text and press the capture button.

Copy Text: The extracted text will be displayed immediately on your screen.

📥 Getting Started

Prerequisites

Android Studio (latest version recommended)

Physical Android device with camera capability.


Open & Sync:
Open the project in Android Studio and wait for Gradle sync to complete.

Run Application:
Connect your physical Android device and click Run ('▶').
